# cs-websites

Websites ontworpen in de **CS Group · Web Hub**.

## Structuur

```
<klant>/
  index.html          nieuwste versie die naar GitHub is gestuurd
  assets/             logo en foto's van de klant
  versies/            eerdere versies (datum-stijl.html)
```

## Klanten

<!-- KLANTEN:START -->
_Nog geen websites._
<!-- KLANTEN:END -->

Een website komt hier terecht via de knop **Naar GitHub** in de hub, waarna Claude de export uitvoert.
